Import Shots from CSV

CSV Format

Your CSV file should have the following columns:

  • sequence_number - The sequence number (required)
  • sequence_title - Optional title for the sequence
  • shot_number - The shot number within the sequence (required)
  • script - Script/dialogue for the shot
  • characters - Comma-separated list of character names
  • wardrobe - Comma-separated list of wardrobe items (matching characters by position)
  • background - Background description
  • camera_angle - Camera angle description
  • camera_movement - Camera movement description

Example CSV:

sequence_number,sequence_title,shot_number,script,characters,wardrobe,background,camera_angle,camera_movement
1,Opening,1,"Character A: Hello!","Character A","Casual Outfit","Living Room","Wide shot","Static"
1,Opening,2,"Character B: Hi there!","Character A,Character B","Casual Outfit,Work Clothes","Living Room","Medium shot","Pan right"
2,Action,1,"Both characters run","Character A,Character B","Running Shoes,Athletic Wear","Street","Tracking shot","Follow movement"
